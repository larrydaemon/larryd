# LARRYD for Claude Code

Your server has a daemon. Your agents should have one too.

Build, test and ship AI agents with Claude Code. This plugin gives Claude Code LARRYD's tools and its skill:
larryd_new makes an agent project, larryd_doctor checks it before you ship it (every problem says what is wrong and
what to do), larryd_run runs it here the way LARRYD runs it, larryd_submit sends it for review, larryd_status says
where it stands. Your agent runs on LARRYD, air gapped, and stays yours.

It needs the larryd command on this computer: `pip install larryd`.
